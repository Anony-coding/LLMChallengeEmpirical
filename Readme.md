# Understanding LLM-Centric Challenges in Deep Learning Frameworks: An Empirical Analysis

This repo is for the paper of  **Understanding LLM-Centric Challenges in Deep Learning Frameworks: An Empirical Analysis**.

It contains the data, scripts, annotations, and supplementary materials used in our study. These files support the processes of issue collection, keyword-based filtering, relevance validation, manual inspection, and quantitative analysis described in the paper.

## File Descriptions

### `allissuereports.txt`
This file contains the URL links of the original issue reports collected in our study.

### `chatgptsummaryvalidation.csv`
This file is used to validate the summaries generated by ChatGPT.

- **Column 1:** sampled issue reports  
- **Column 2:** generated summaries  
- **Column 3 and Column 4:** annotations indicating whether the generated summary is sufficient to support a judgment on whether the issue is related to LLMs  

### `filter_keywords.py`
This script contains the keyword lists used to filter issue reports from the three studied frameworks.

### `final_url_category.json`
This JSON file maps each issue report URL to its final assigned label.

### `keywordcatchreport.txt`
This file contains the issue reports retained after keyword-based filtering using `filter_keywords.py`.

### `keywordvalidation.json`
This file records the annotations provided by three volunteers on whether an issue report is related to LLMs.

- **1** indicates that the issue is considered **LLM-related**

### `manualinspection.json`
This file contains the manual inspection results for the issue reports in `keywordcatchreport.txt`.

- **1** indicates that the issue is related to LLMs  
- **0** indicates that the issue is not related to LLMs  
- The final labels are represented as:  
  - **Y** = Yes  
  - **N** = No  
  - **U** = Unclear  

### `quantitative_framework.csv`
This file presents the quantitative classification results, including the number of issues in each category for each framework.

### `validation_finalcategory.csv`
This file is used in the supplementary experiment.

- We sampled **400** issue reports  
- **Column 2:** final label  
- **Last two columns:** labels assigned by two new volunteers  

### `Interviewee Background.xlsx`
This file introduces the details of the interviewees including the roles, gender, experienced years for using LLMs or developer DL frameworks, and the specific duties related to LLMs.

### `Interview GuideLine.md`
This file is structured into four parts and covers participants’ backgrounds, usability questions, bug-related issues, and desired framework improvements. The guide supports validating and extending a taxonomy of LLM-related challenges in DL frameworks through semi-structured, 30–40 minute interviews.

### `CodeBook.csv`
This file is an Excel spreadsheet that summarizes interview findings from both LLM users and deep learning framework developers, focusing on challenges related to LLM development. Each entry includes participant type, experience level, framework context, a key quote, linked taxonomy categories, and synthesized research insights. The data supports analysis of common pain points, framework bugs, and unmet needs in LLM workflows.
